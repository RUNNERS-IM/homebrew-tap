# RUNNERS-IM Homebrew tap

```sh
brew install --cask runners-im/tap/split
```

| Cask | App |
|---|---|
| `remote` | [Remote](https://github.com/RUNNERS-IM/remote) — see and click the screens of other computers, from the menu bar (macOS 14 or later) |
| `split` | [Split](https://runners.im/tools/split) — move and resize Mac windows with keyboard shortcuts (successor of Spectacle) |

The cask is updated automatically when a new Split release is published.
